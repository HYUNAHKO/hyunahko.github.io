Research Interests

My research goal is to develop advanced frameworks for 3D scene understanding and generation that enable (1) physically plausible 3D dynamic synthesis, (2) high-quality neural rendering with accurate material modeling, and (3) seamless integration with generative AI models. Particularly, my interests include:

  • Physics-based 3D dynamic scene synthesis
  • Diffusion models for 3D content generation
  • Neural rendering and 3D Gaussian Splatting

Multi-View Diffusion Gaussian Splatting (MVDGS)
Dec. 2024 – Present | Team Leader
code / project page

Research Project
Developed a novel view synthesis system combining CameraCtrl and 3D Gaussian Splatting to generate controllable 3D objects from single images with temporal consistency. Integrated multi-view diffusion models with 3DGS representation to enable high-quality novel view synthesis while maintaining 3D consistency. The system generates multiple camera viewpoints of the same object and reconstructs them into a coherent 3D Gaussian representation, enabling real-time rendering and interactive manipulation of generated 3D content.

Recipe Recommendation via Object Detection and Knowledge Graph QA
Oct. 2024 – Nov. 2024 | Team Leader
code / demo

Course Project: Introduction to AI and Its Application
Built an end-to-end recipe recommendation system that detects ingredients from images using YOLOv5, generates personalized recipes with knowledge-augmented LLM prompts, and creates visually appealing food images using Stable Diffusion. Implemented a user-friendly interface allowing real-time ingredient detection and customized recipe generation based on dietary preferences and available ingredients.

Room Generation with Stable Diffusion and ControlNet
Apr. 2024 – May. 2024 | Team Leader
code / demo

Course Project: Artificial Intelligence
Trained a customized generative model combining ControlNet and Stable Diffusion for personalized interior design. The system generates photorealistic room images conditioned on segmentation maps and depth information, enabling users to visualize different interior design options. Fine-tuned the model on custom interior design datasets to improve quality and style consistency for various room types and design preferences.

Generative Pet Memorials with LLaMA3 and Stable Diffusion
Aug. 2024 – Sep. 2024
code

Personal Project
Created a personalized pet memorial system that generates heartfelt letters and artistic images commemorating beloved pets. Fine-tuned LLaMA3 using LoRA for emotionally resonant letter generation, and integrated Stable Diffusion with ControlNet for style-consistent memorial artwork. Applied style transfer techniques to match various artistic preferences, providing comfort to pet owners through AI-generated personalized tributes.
